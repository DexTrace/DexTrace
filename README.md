## 🚀 Featured Project

### 🧩 [JADX Studio](https://github.com/DexTrace/jadx-studio)

Desktop **decompiler GUI + batch CLI** for Android artifacts, built on the jadx engine.

- Package/class tree browser, resources and native library views
- Editable syntax-highlighted editor with line numbers and dirty markers
- **Java | Smali split view** — verify the reconstruction against real Dalvik
- Deobfuscation mapping editor with reproducible `.jobf` export
- Native `.so` analysis: ELF parsing, radare2/rizin disassembly, Ghidra headless C pseudocode
- Binary AXML decoder, packer/protector detection, PairIP/jiagu unpacking
